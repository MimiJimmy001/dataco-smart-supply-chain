# 看板设计方案（4 页）

## 建模关系

```
dim_date[date]        1 ─── *  fact_order_items[order_date]
dim_customer[Customer Id] 1 ── * fact_order_items[customer_id]
dim_product[Product Card Id] 1 ─* fact_order_items[product_id]
```
导入后如未自动识别关系，在"模型"视图手动拖拽建立；交叉筛选方向保持单向。

## 第 1 页 · 经营总览

**视觉对象**：
- 顶部 KPI 卡 ×5：有效销售额、有效利润、利润率、有效订单数、平均客单价
- 折线+柱形组合图：月度销售额（柱）+ 销售额同比（线），X 轴 dim_date[year_month]
- 条形图：按市场(Market)销售额排名
- 环形图：客户 Segment 销售额占比
- 切片器：年份、市场

**要点**：同比用 `SAMEPERIODLASTYEAR`，必须配合 dim_date 表才生效。

## 第 2 页 · 交付绩效（核心故事页）

**视觉对象**：
- KPI 卡 ×3：延迟交付率、平均发货天数、平均延迟偏差
- 矩阵：运输方式 × 订单区域 的延迟率，条件格式背景色阶（红=高延迟）
- 条形图：按运输方式延迟率排序（First Class 100% → Standard 39.6%）
- 折线图：月度延迟率趋势
- 地图：按 Order State 的延迟率气泡（ Latitude/Longitude ）

**业务结论**：运输方式等级越高延迟越严重（First Class 全部延迟、Second Class 79.5%），
计划发货天数设置与实际产能错配是主因，建议重估 First/Second Class 的承诺时效。

## 第 3 页 · 品类与利润

**视觉对象**：
- 分解树：有效利润按 市场 → 部门 → 品类 逐级钻取
- 散点图：X=平均折扣率，Y=利润，气泡=销售额，明细=品类；加趋势线
- 条形图：Top10 / Bottom10 产品利润
- KPI 卡：亏损订单占比、亏损金额

**业务结论**：亏损订单占比 18.7% 且均匀分布于各部门（17.6%~18.9%），
非单一品类问题，指向全局定价/折扣策略；散点图可进一步定位亏损集中的品类区间。

## 第 4 页 · 区域市场

**视觉对象**：
- 填充地图：按 Order Country 销售额
- 堆积柱形图：区域 × 客户 Segment 销售额
- 表格：Top10 城市（销售额、利润、延迟率三列，延迟率数据条展示）
- 卡片：Europe $10.4M、LATAM $9.8M、Pacific Asia $7.9M 三大市场对比

## 交互设计

- 每页左上角放"重置筛选器"按钮（书签实现）
- 页面间用按钮导航（首页放 4 个入口）
- 统一主题色：深蓝主色 + 橙红预警色（延迟/亏损）
- 所有金额格式化为 `$#,##0,.0K` 或百万级 `$#,##0,,.0M`
